To build the docs webpage locally:

```bash
pip install -r requirements.txt
cd docs
make html
```

(`requirements.txt` pins Sphinx, the Read-the-Docs theme and `sphinx-toolbox`,
which provides the `collapse` directive used in these pages.)

Open `build/html/index.html` in your browser.

Documentation available at: [ALATDYN](https://aladyn.readthedocs.io/en/latest/index.html)
